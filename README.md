# To‑Do List (Vanilla JS)

Small, polished to‑do list using only HTML, CSS, and vanilla JavaScript. Data is stored locally in the browser using `localStorage`.

Open `index.html` in a browser to run.

Features:
- Add tasks with priority (Low default, Medium, Urgent)
- Mark complete with checkbox (shows strikethrough)
- Delete tasks
- Counts for completed/incomplete tasks
- Persistent storage via `localStorage`

Design: responsive, minimal, blue-based palette, accessible controls.
